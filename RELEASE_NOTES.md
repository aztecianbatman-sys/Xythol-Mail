# Xythol Mail 0.1 Demo

This is the first downloadable demo build of Xythol Mail.

### Included

- Windows Electron 37.2.6 desktop app
- Supabase anonymous name-based account flow
- Supabase Postgres schema and RLS migration
- Research workspace
- Integrated Chromium research browser
- Source and selection capture tools
- Research-to-email workflow UI
- Email composer
- Real SMTP sending
- Local draft saving
- Contacts and templates sections
- Privacy Center
- Settings
- Command palette with Ctrl+K
- Custom Xythol Mail branding
- Secure Electron preload boundary

### Important setup

The demo needs a Supabase project. Copy `.env.example` to `.env.local`, add the project URL and publishable key, and enable Anonymous Sign-Ins in Supabase Authentication.

Run the SQL migrations in `supabase/migrations/` before using cloud-backed research and contacts.

SMTP sending requires your own SMTP server details.

### What is not pretending to be finished

Gmail and Outlook OAuth, full mailbox synchronization, scheduled sending, complete offline conflict resolution, and destructive cloud-account deletion still require their provider/server-side setup.

The inbox screens stay empty instead of showing fake messages.
