# Xythol Mail 0.1 Demo

This is the first downloadable demo build of Xythol Mail.

## Included

- Windows desktop app built with Electron 37.2.6
- Supabase anonymous name-based accounts
- Supabase Postgres schema with Row Level Security
- Research workspace
- Integrated Chromium research browser
- Source and selection capture
- Research-to-email workflow UI
- Email composer
- Real SMTP sending
- Local draft saving
- Contacts and templates sections
- Privacy Center
- Settings
- Ctrl+K command palette
- Custom Xythol Mail branding

## Setup

The demo needs a Supabase project. Copy .env.example to .env.local, add the project URL and publishable key, and enable Anonymous Sign-Ins in Supabase Authentication.

Run the SQL migrations in supabase/migrations/ before using cloud-backed research and contacts.

SMTP sending requires your own SMTP server details.

## Not pretending to be finished

Gmail and Outlook OAuth, full mailbox synchronization, scheduled sending, complete offline conflict resolution, and destructive cloud-account deletion still need their provider/server-side setup.

Inbox screens stay empty instead of showing fake messages.

## Download
